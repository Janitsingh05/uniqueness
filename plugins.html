Export & workflow

Every project leaves the studio in a format your editor already understands — a burned-in MP4, or a caption file you drop straight onto a timeline.

Premiere Pro

File → Import your .srt, then drag it from the Project panel onto a track above your video. Premiere turns it into a caption track you can restyle. For the animated look, import the burned-in .mp4 instead.

DaVinci Resolve

In the Edit page, right-click the Media Pool → Import Subtitle, pick your .srt, and drag it to the subtitle track. Resolve keeps the timing exactly as exported.

Final Cut Pro

File → Import → Captions, choose the .srt, and attach it to your primary storyline. Use .vtt if you are heading straight to the web.

CapCut

Captions → Import captions accepts the .srt directly on both desktop and mobile. Or skip the step entirely and post the burned-in .mp4 as it is.
